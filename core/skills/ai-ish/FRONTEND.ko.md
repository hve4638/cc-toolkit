# 프론트엔드 점검 목록

## 과잉 설명

사용자에게 필요 없는 문구다. 어시스턴트의 말투가 제품에 새어 나온 것이다.

- 화면이 이미 보여 주는 동작의 설명: 라벨이 이름 붙인 것을 다시 설명하는 placeholder, 버튼이 하는 일을 풀어 쓴 모달 문단.
- 화면에 이미 있는 정보의 재진술: 제목을 바꿔 말하는 설명, 확인 창에서 한 말을 반복하는 토스트.
- 동작 원리 나열: 시스템이 무엇을 언제 어떻게 하는지, 화면이 이미 보여 주는데도 적은 것 (예: 항목마다 붙은 배지).
- 사용자의 말이 있는데 쓴 구현 용어: "가리킨다", "cache", "동기화 작업", "레코드".
- 빼도 뜻이 같은 안심시키는 말: "지금은", "먼저", "안전하게", "걱정하지 마세요".
- 도움말에 끼워 넣은 예시: "…처럼", "예를 들어 …".
- 라벨, 툴팁, 배너, 빈 상태에 넣은 단축키 안내.
- 축하: "완료!", "다시 오신 걸 환영합니다!", 느낌표, 라벨과 메시지의 이모지, 사용자가 이미 보는 변경 뒤에 뜨는 성공 토스트.
- 라벨이나 아이콘이 이미 하는 일을 말하는 컨트롤에 붙은 툴팁.
- 어느 제품에나 맞는 문구: "Unlock …", "Seamless", "Get started", "Learn more".

데이터 손실이나 되돌릴 수 없는 동작에 대한 경고, 문제와 복구 방법을 말하는 오류 메시지는 남긴다.

고치기: 각 문구를 사용자가 행동하는 데 필요한 만큼으로 줄인다. 긴 설명은 한 문장이 되거나 사라진다. 줄인 문구는 지운 부분 없이도 한 번에 읽혀야 한다.

## 실속 없는 풍부함

사용자에게 쓸모는 없고 화면이 완성돼 보이게만 하는 것들이다.

- 지어낸 데이터: 지어낸 지표 ("10x faster", "+12.5%"), placeholder 이름 (Jane Doe, Acme), 실제처럼 보여 준 샘플 숫자.
- 아무것과도 연결되지 않은 표시: 실제 상태를 읽지 않는 status dot, 배지, progress ring, sparkline.
- 죽은 컨트롤: 핸들러 없는 버튼, `href="#"`, 아무것도 바꾸지 않는 메뉴 항목과 설정.
- 가능한 숫자를 전부 같은 무게로 보여 주고, 사용자의 주된 질문에 답하는 요소는 없는 대시보드.
- 쓰는 자리가 아니라 한 번에 모두 보이는 기능. 한 뷰에 둘 이상인 주 동작.
- 빠진 상태: 빈 상태, 로딩, 오류 상태가 없는 목록이나 데이터 뷰.
- 일상 동작에 끼어드는 것: 되돌릴 수 있는 동작의 확인 모달, 모든 동작마다 뜨는 토스트.

고치기: 지어낸 데이터는 실제 데이터나 표시된 placeholder 로 바꾸고, 다른 지어낸 값으로 바꾸지 않는다. 빠진 상태를 더한다. 표시, 죽은 컨트롤, 모달을 연결하거나 빼는 것은 먼저 묻는 항목이다.

## 따로 노는 디자인

하나의 체계가 아니라 컴포넌트마다 고른 값이다.

먼저 목록을 만든다. 대상에 있는 border-radius, 색 (utility class 와 raw 값), 그림자, 글꼴, 글자 크기, 간격 (padding, margin, gap) 의 서로 다른 값을 모두 모으고 각각의 개수를 센다.

- 프로젝트의 토큰이나 스케일 밖의 값, 한 번만 쓰인 값.
- 같은 역할의 요소끼리 다른 radius, 또는 크기와 상관없이 모든 요소에 같은 radius (버튼, 입력, pill, 아바타, 카드 모두).
- 둘 이상의 회색 계열 (slate, gray, zinc 혼용), 둘 이상의 강조색, 컴포넌트마다 다른 채도.
- padding 이나 gap 이 서로 다른 같은 종류의 형제 요소.
- 섞인 아이콘 세트나 선 굵기, 아이콘 대신 쓴 이모지.
- 페이지의 글꼴, 팔레트, 모양, 밀도를 따르지 않는 섹션.

고치기: 흩어진 값을 기존 토큰이나 스케일에 맞춘다. 프로젝트에 그런 것이 없으면 역할마다 가장 많이 쓰인 값을 쓰고, 그 선택을 보고에 기록한다.

## 템플릿 기본값

학습 데이터의 평균을 이 제품에 맞는 이유 없이 쓴 것이다. 이 절의 모든 항목은 취향 문제다.

- 유일한 서체로 쓴 Inter 나 시스템 글꼴.
- 보라, 남색, 바이올렛 그라데이션, 그라데이션 텍스트, 색이 있는 glow 와 그림자.
- 페이지 구조로 쓴 똑같은 아이콘 카드 세 개, 카드 안의 카드, 둥근 색 사각형 안의 아이콘.
- 카드 한쪽 가장자리의 색 줄무늬.
- 모든 제목 위의 eyebrow 라벨, 01/02/03 번호를 단 섹션, 모두 가운데 정렬.
- 장식으로 쓴 유리 효과와 blur, 장식용 blob, orb, 물결 구분선.
- 모든 요소에 똑같이 붙은 hover 확대, bounce, fade-in.

## 수정 후 확인

고친 뒤, 바뀐 화면을 브라우저에서 하나씩 보고 줄인 문구를 제자리에서 읽는다. 화면을 렌더링할 수 없으면 이 확인을 Not checked 에 기록한다.
