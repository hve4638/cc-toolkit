# handoff

사용자가 넘기려는 작업을 HANDOFF 파일로 저장해, 다른 디렉토리에서 뜨는 맥락 0 의 세션이 받아 실행할 수 있게 한다. 그 작업에 필요한 것만 선별해 담는다.

---

## 저장 위치

우선순위:

1. 사용자가 명시한 위치
2. 그 작업이 속한 작업 디렉토리 (있는 경우)
3. 그 외에는 프로젝트 루트

## 파일명

- 작업 디렉토리에 저장: `HANDOFF.md`. 다른 handoff 와 공존해야 하면 짧은 작업명을 붙인다 (`HANDOFF.<짧은작업명>.md`).
- 프로젝트 루트에 저장: `HANDOFF.<짧은작업명>.md`.
- 대상 파일이 이미 존재하면 첫 줄을 사용자에게 보여주고 덮어쓸지 물어본다.

## 내용

고정 구조 없음. 수신 세션이 되묻지 않고 실행하는 데 필요한 것을 쓴다:

- 무엇을, 왜 — 목표와 그 배경
- 수신자가 알 수 없는 맥락: 제약, 이미 내린 결정과 그 이유
- 코드 참조는 파일 경로 + 라인 번호 + 의도만

크기 기준: "맥락 0 의 세션이 이 파일만으로 실행 가능한가?"
