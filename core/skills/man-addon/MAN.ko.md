# addon

애드온은 core 의 세션 확장 기능이다: 세션 시작, 도구 호출 전후, 턴 종료 같은 Claude Code 훅 이벤트에서 도는 기능들이다. 어떤 것은 항상 돌고, 어떤 것은 이름 붙은 규칙 뒤에 잠겨 있어 켜기 전에는 돌지 않는다. 규칙을 켜면 해당 세션에서 에이전트가 받는 지시나 허용 범위가 달라진다 — 주입되는 안내, 도구 호출 가드 같은 것들이다.

## 켜는 곳

규칙은 agentaddon `event` 파일에서 켜고 끈다. 한 줄에 항목 하나다.

| 파일 | 범위 |
|---|---|
| `~/.config/agentaddon/event` | 전역 — 모든 세션, 가장 먼저 읽힌다 |
| `<디렉터리>/.config/agentaddon/event` | 세션 루트의 각 조상 디렉터리, 파일시스템 루트부터 |
| `<세션 루트>/.config/agentaddon/event` | 가장 가까움 — 이긴다 |

파일들을 위 순서로 이어붙여 위에서 아래로 읽고, 한 항목의 상태는 **마지막으로 매치된 줄**이 정한다 — 그래서 세션에 가까운 층이 이긴다. 세션 루트는 세션이 시작된 위치 (`.claude` 가 있는 곳) 이고 세션 시작 시점에 고정되어, 이후 작업 디렉터리를 옮겨도 따라가지 않는다. 조상 층은 워크스페이스식 중첩을 위한 것이다 — 워크스페이스 폴더에 한 줄 적어두면 그 아래 어느 repo·워크트리에서 세션을 열어도 적용된다.

## 줄 문법

```
# 켜기:
rule-name
# 인자와 함께 켜기 (키만 적으면 참):
rule-name@key=value,flag
# 끄기:
!rule-name
# 여기까지 나열된 전부 끄기 — 앞선 층의 항목 포함:
!*
```

- 빈 줄과 `#` 로 시작하는 줄은 무시된다. 줄 끝 주석은 없다 — 이름 뒤에 같은 줄로 무엇이든 붙으면 그 줄 전체가 조용히 무효가 된다.
- 이름은 소문자 영문자·숫자·`-`·`:` 로 쓴다. `rule:banaction` 의 `rule:` 같은 접두어는 이름짓기 관례일 뿐 문법이 아니다.
- `*` 는 부정에서만 쓰며 패턴의 어느 위치에서든 임의 문자열에 매치한다: `!know:*` 는 `know:` 로 시작하는 전부를 끄고, `!*` 뒤에 다시 적은 이름은 다시 켜진다.
- 뒤에 온 줄은 앞의 줄을 **인자까지 통째로** 대체한다 — 인자 집합을 키 단위로 병합하지 않는다. 부정은 이름만 보고 인자는 무시한다.
- 모르는 이름은 무시된다 — 오타는 조용히 아무 일도 하지 않는다.

## 무엇을 켤 수 있나

이 설치본이 아는 규칙 이름 목록은 `/available-addon-rule` 로 확인한다. 각 규칙이 무엇을 하는지는 그 규칙 자신의 문서가 설명한다 (예: `rule:banaction` 은 `/man-banaction`).

## 항상 도는 애드온

설정과 무관하게 항상 도는 애드온도 있다. 이들은 규칙 이름이 없어 목록에 실리지 않고, `!*` 로도 닿지 않는다. 전부 부정했는데도 남아 있는 동작이 있다면 이 부류다.

## 스위치만 담는다

agentaddon 에는 무엇을 켤지만 적는다. 기능의 실제 설정은 그 기능 자신의 파일에 있다 — `rule:banaction` 을 켜면 세션이 `.banaction` 파일들을 읽는 것이지, 차단 규칙들이 agentaddon 으로 옮겨오는 것이 아니다. 인자는 스위치에 딸린 작은 손잡이지 설정을 담는 그릇이 아니다.
