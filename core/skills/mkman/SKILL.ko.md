# mkman

사용자가 지정한 스킬을 분석해, 그 스킬 폴더 안에 사용자용 설명서 `MAN.md` 를 생성한다.

---

## 1. 대상 폴더 결정

- 작업 repo 의 `*/skills/<스킬명>/` 을 먼저 찾는다.
- repo 에 없으면 플러그인 캐시에서 찾는다: `~/.claude/plugins/installed_plugins.json` 에 기록된 각 플러그인의 `installPath` 아래 `skills/<스킬명>/`. 거기 속하지 않는 캐시 버전 폴더는 과거 잔재이므로 매칭하지 않는다.
- `플러그인:스킬` 형태로 지정되면 플러그인 세그먼트를 함께 매칭한다.
- 0곳 → 대상이 없음을 알리고 종료. 서로 다른 스킬이 2곳 이상 → 목록을 제시하고 사용자에게 선택을 요청한다.
- 대상이 캐시 폴더라면, 플러그인 업데이트 시 생성물이 사라진다는 점을 보고에 명시한다.

## 2. 분석

대상 폴더의 `SKILL.md` 와 그것이 링크한 참조 파일·`scripts/` 를 읽고 파악한다: 용도, 호출법 (인자·모드), 동작 절차, 산출물, 주의점.

읽은 내용만으로 불분명한 동작은 추측으로 서술하지 않고 "미확인" 으로 표시한다.

## 3. MAN.md 작성

frontmatter 에 `description` (색인용 한 줄) 필수. 본문은 영어로, 사람이 읽는 설명서 산문으로 쓴다 — 실행 모델에게 지시하는 문체가 아니다.

섹션 골격 (해당 없는 절은 생략):

- 용도 — 이 스킬이 해결하는 문제
- 호출법 — 인자와 모드
- 동작 — 실행하면 무슨 일이 일어나는지
- 산출물 — 생성 파일·보고 형식
- 주의 — 부작용, 전제, 한계

이미 `MAN.md` 가 있으면 덮어쓰기 전에 사용자에게 확인한다.

## 4. 보고

생성 경로와 description 한 줄을 보고한다.
