# pickup

`.agent-memory/HANDOFF.md` 를 인덱스 헤더부터 읽고, 가져온 내용 요약만 사용자에게 보여준다. 사용자가 명시적으로 지시할 때까지 작업은 진행하지 않는다.

---

## 동작 순서

### 1. 확인
`.agent-memory/HANDOFF.md` 존재 여부를 확인.

- 없음 → 이어받을 handoff 없음을 사용자에게 알리고 종료
- 있음 → 즉시 로드

### 2. 로드
- **인덱스 헤더를 먼저** 읽는다
- 헤더의 진입점 안내와 의존관계에 따라 작업 섹션을 순회
- 읽은 내용을 현재 세션의 작업 기반으로 삼는다

### 3. 삭제
로드 성공 확인 후 `.agent-memory/HANDOFF.md` 를 삭제한다 — 재호출 시 같은 handoff 가 반복 등장하지 않도록.

---

## 다음 할 일 응답 규칙

사용자가 별도 지정 없이 "다음 할 일", "이어서 뭐 해", "어디서부터" 같은 식으로 물으면, **인덱스 헤더의 "현재 컨텍스트" 로 지정된 작업 섹션의 "다음 수" 만 출처로 삼는다**.

- `[done]` 으로 표시된 다른 작업 섹션에 "다음 수" 가 보여도 이미 종결된 일이므로 제안하지 않는다.
- 현재 컨텍스트가 `없음 (세션 종결)` 이면 "이어받을 활성 작업 없음" 으로 답하고, 새 지시를 사용자에게 요청한다.
- 현재 컨텍스트가 누락된 handoff 라면 사용자에게 어느 섹션을 이어갈지 묻는다.
