이 워크트리는 부모 브랜치에 squash 단일 커밋으로 올리기 위한 작업장이다. 명령은 워크트리 안의 `./wt` 하나이고 동사 세 개를 받는다.

- 어차피 커밋 하나로 합쳐지므로, 작업 중에는 필요할 때마다 자유롭게 커밋한다.
- 버전 bump처럼 한 번만 반영돼야 하는 변경은 마지막 merge 직전에 한 번만 한다. 중간에 여러 번 하면 합쳐질 때 의미가 없거나 꼬인다.

**작업을 부모에 올릴 때** (사용자가 "merge 해"): `./wt merge -m "<메시지>"`. 커밋들을 하나로 합쳐 부모 브랜치에 올린다. **워크트리는 그대로 남는다.**

- **커밋된 것만 올라간다.** 미커밋 변경은 merge 동안 stash 로 치워졌다가 그대로 돌아온다. 올릴 작업은 먼저 커밋한다.
- merge 직후 이 브랜치는 부모와 같은 커밋이 되므로, 이어서 작업하고 또 merge 하면 된다. 몇 번을 반복해도 이미 올라간 작업이 충돌로 되살아나지 않는다.
- 부모가 아닌 다른 브랜치로 올리려면 `--into=<브랜치>`.
- 커밋을 하나로 합치지 않고 그대로 올리려면 `--no-squash`. 이때는 합칠 커밋이 없어 `-m` 을 같이 주면 거부한다.
- 충돌을 예고하며 멈추면 아무것도 바뀌지 않은 상태다. 안내대로 이 워크트리에서 `git merge <부모>` 로 화해시키고 커밋한 뒤 다시 merge 한다.

**올리고 작업장까지 끝낼 때** (사용자가 "land 해"): `./wt land -m "<메시지>"`. merge 에 이어 destroy 까지 한다. 인자는 merge 와 같다.

- **미커밋 변경이 있으면 아무것도 하지 않고 거부한다.** land 는 둘 다 하거나 아무것도 안 한다. 올릴 것은 커밋하고, 남길 것이 있으면 `merge` 와 `destroy` 를 따로 부른다.
- 이미 merge 를 해둬서 올릴 게 없으면 merge 를 건너뛰고 바로 정리한다.

**작업장을 정리할 때** (사용자가 "정리해" / "버려"): `./wt destroy`. 이 워크트리와 브랜치를 없앤다.

- 부모에 이미 반영됐고 작업트리가 깨끗하면 그냥 정리된다. merge 직후가 그 상태다.
- 아직 안 올라간 커밋이나 미커밋 변경이 있으면 confirmation key를 출력하고 멈춘다. 잃을 게 있다는 뜻이니, 정말 버릴 거면 안내된 키를 붙여 재실행한다.

작업이 끝났으면 `./wt land -m "..."` 한 줄이다. 워크트리를 남겨두고 이어서 쓸 거면 `./wt merge -m "..."` 만 한다.
