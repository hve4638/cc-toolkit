이 워크트리는 부모 브랜치로 squash merge 하기 위한 일회용 작업장이다. 끝나면 누적 작업이 부모에 단일 커밋으로 들어간다.

- 어차피 커밋 하나로 합쳐지므로, 작업 중에는 필요할 때마다 자유롭게 커밋한다.
- 버전 bump처럼 한 번만 반영돼야 하는 변경은 마지막 squash merge 직전에 한 번만 한다. 중간에 여러 번 하면 합쳐질 때 의미가 없거나 꼬인다.
- 작업을 부모에 올릴 때 (사용자가 "land 해"): `./wt-land -m "<메시지>"`. 워크트리의 커밋들을 부모 브랜치에 squash 단일 커밋으로 올린 뒤 이 워크트리와 브랜치를 정리한다.
- 한 워크트리에서 여러 작업을 나눠 올릴 때 (사용자가 "land keep 해"): `./wt-land -m "<메시지>" --keep`. 올린 뒤 워크트리를 남겨 이어서 또 올릴 수 있다(land 마다 부모에 커밋 하나). 마지막엔 `--keep` 를 빼서 정리하거나 `./wt-destroy` 로 폐기한다.
- 작업을 버릴 때: `./wt-destroy`. 이 워크트리를 폐기한다. 손댄 내용이 있으면 confirmation key를 출력하고 멈추니, 안내된 키를 붙여 재실행해 확정한다.
</worktree_instruction>
