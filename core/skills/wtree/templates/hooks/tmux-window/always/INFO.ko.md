모든 wtree new 마다 claude 를 띄운 tmux 윈도우 생성 — 포커스는 직접 쳤을 때만 이동

`wtree new` 직후 tmux 윈도우를 하나 열어 새 워크트리 디렉터리에서 `claude` 를 시작한다 — 모든 실행에서. 터미널에서 직접 친 실행이면 새 윈도우로 포커스가 이동하고, 에이전트나 백그라운드 실행이면 현재 포커스를 유지한 채 뒤에 열린다. tmux 밖에서는 아무것도 하지 않는다. `wtree new <이름> -- <단어들>` 로 실행하면 `--` 뒤 전부가 claude 의 초기 프롬프트로 전달된다.

설치된 `.git/wtree/hooks/` 의 파일은 평범한 sh 다 — 실행 명령이나 윈도우 이름을 바꾸려면 그 파일을 직접 고친다.
