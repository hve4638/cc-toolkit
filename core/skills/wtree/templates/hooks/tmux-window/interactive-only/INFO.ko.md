터미널에서 직접 친 wtree new 만 claude 윈도우 생성·포커스 이동 — 에이전트 실행은 무시

터미널에서 직접 친 `wtree new` 직후 tmux 윈도우를 하나 열어 새 워크트리 디렉터리에서 `claude` 를 시작하고 포커스를 옮긴다. 비대화 실행(에이전트가 부른 wtree)에서는 윈도우를 아예 만들지 않는다. tmux 밖에서는 아무것도 하지 않는다. `wtree new <이름> -- <단어들>` 로 실행하면 `--` 뒤 전부가 claude 의 초기 프롬프트로 전달된다.

설치된 `.git/wtree/hooks/` 의 파일은 평범한 sh 다 — 실행 명령이나 윈도우 이름을 바꾸려면 그 파일을 직접 고친다.
